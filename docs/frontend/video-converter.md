# UI: Conversor de Vídeo

## Ubicación

Página `/conversor`, pestaña **Video** — accesible desde el Home pulsando la card **Conversor**.

## Qué ve el usuario

Una zona de arrastrar y soltar, selector de formato de destino y botón de conversión. Un aviso discreto recuerda que los archivos grandes pueden tardar varios minutos.

## Flujo de Uso

1. El usuario selecciona la pestaña "Video".
2. Arrastra o selecciona un archivo de vídeo.
3. El nombre del archivo aparece en la zona de drop.
4. Elige el formato de destino (MP4, AVI, MKV).
5. Pulsa "Convert".
6. Cuando finaliza, el navegador descarga el archivo como `result.{formato}`.

## Formatos Disponibles

MP4 · AVI · MKV

## Aviso

Los archivos grandes pueden tardar varios minutos en procesarse. No cerrar el navegador durante la conversión.
