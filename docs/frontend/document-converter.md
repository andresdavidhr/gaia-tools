# UI: Conversor de Documentos

## Ubicación

Página `/conversor`, pestaña **Document** — accesible desde el Home pulsando la card **Conversor**.

## Qué ve el usuario

Una zona de arrastrar y soltar, selector de formato de destino y botón de conversión. Un aviso discreto informa de las limitaciones en la conversión de PDF a DOCX.

## Flujo de Uso

1. El usuario selecciona la pestaña "Document".
2. Arrastra o selecciona un documento (PDF, DOCX o TXT).
3. El nombre del archivo aparece en la zona de drop.
4. Elige el formato de destino disponible.
5. Pulsa "Convert".
6. Cuando finaliza, el navegador descarga el archivo como `result.{formato}`.

## Formatos Disponibles

PDF · DOCX · TXT

## Aviso

La conversión de PDF a DOCX puede no preservar el diseño exacto del documento original.
