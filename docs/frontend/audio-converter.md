# UI: Conversor de Audio

## Ubicación

Página `/conversor`, pestaña **Audio** — accesible desde el Home pulsando la card **Conversor**.

## Qué ve el usuario

Una zona de arrastrar y soltar, selector de formato de destino y botón de conversión.

## Flujo de Uso

1. El usuario selecciona la pestaña "Audio".
2. Arrastra o selecciona un archivo de audio.
3. El nombre del archivo aparece en la zona de drop.
4. Elige el formato de destino (MP3, WAV, OGG).
5. Pulsa "Convert".
6. Cuando finaliza, el navegador descarga el archivo como `result.{formato}`.

## Formatos Disponibles

MP3 · WAV · OGG
